# TechTrek — SDMIT 3D Campus Treasure Hunt

> **SparDhaM 2026 presents Tech Trek**  
> An interactive 3D digital-twin campus treasure hunt website for **SDM Institute of Technology (SDMIT)**, Ujire, Karnataka, India.

---

## 🏛️ Event Overview
- **Event:** Tech Trek (Technical Treasure Hunt)
- **Fest:** SparDhaM 2026
- **Date:** 30/10/2026
- **Venue:** SDM Institute of Technology, Ujire
- **Team Size:** 3–4 Members per Team

---

## 🚀 Features
- **Cinematic SparDhaM 2026 Intro Animation:** High-production 6-phase opening sequence with glowing gold typography, light sweep, and smooth transition.
- **Dedicated 3D Campus Digital Twin (`/3d-campus`):** Powered by Three.js and the authentic SDMIT campus Blender 3D model (`sdmit_campus.glb`).
- **Aspect-Ratio & Touch Optimization:** Dynamic portrait camera calculations, single-finger orbit, two-finger pan, and pinch zoom.
- **Mobile Floating Action Dock:** Finger-friendly 48px touch targets for Reset View, 2D Floor Plan Map, and Fullscreen toggle.
- **High-Resolution 2D Architectural Map Modal:** Instant campus orientation and floor navigation.
- **Clean Responsive Landing Experience:** Hero showcase with authentic SDMIT campus photographs, event parameter matrix, and direct access controls.

---

## 🛠️ Tech Stack
- **Framework:** React 18, Vite
- **3D Graphics:** Three.js (`three`, `GLTFLoader`, `OrbitControls`)
- **Styling:** Vanilla CSS with custom modern design system & fluid typography
- **Icons:** `lucide-react`

## 💻 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Shreyash1905/TechTrek.git

# Navigate to project directory
cd TechTrek

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
